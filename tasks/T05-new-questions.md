# T05 补题与参考答案

- 状态：未开始
- 负责：Codex（出题并用 SQL 算参考答案）；独立重算在 T05b 由 Claude Code 做
- 模式：题库（`cd ~/semdebt/semantic-debt-eval && codex "执行任务卡 T05"`）
- 限制：不得读取主仓库 `semantic/` 下除 `conventions.md` 以外的文件（避免对着 L1 文档出题）
- 依赖：T04
- 预算：0

## 目标

补约 20 道外部基准没覆盖或覆盖太少的题，并把每类复杂度来源补到至少 8 道。

## 题目类别（来自设计 v5）

| 类别 | 题数 | 例子 |
|---|---|---|
| 业务说法与同义词 | 4 | 上季度线上 GMV 是多少；各品类的净销售额 |
| 相近门店名 | 3 | 迈阿密的门店上个月卖了多少（数据里有同城、编号不同的门店） |
| 企业约定的变体 | 3 | 2009 年各国家的销售额（默认按客户所在地） |
| 计划 vs 实际 | 3 | 2009 年各品类的预算达成率；各门店的销售目标达成率 |
| 实体级派生属性 | 3 | 2009 年每个月末，近 90 天内首次购买的新客各有多少（约定第 14 条） |
| 多步 | 3 | 同店增长最差的 3 家店，各自哪个品类拖了后腿 |
| 财年 | 0–3 | 本财年截至目前的销售额；只在财年与自然年不同时出题，先查日期表 |

另按 T04 的分布报告，补足题数少于 8 道的复杂度来源。

## 要求

- 问句是自然的中文业务问法；用约定清单里的业务词；有歧义的题按「可接受解读」处理。
- 每题打齐 T04 的全部标签。
- 参考答案用 SQL 在 `$SEMDEBT_DATA_DIR/chdb-eval` 上计算，由 `scripts/build_refs.py` 一条命令重算。独立的 pandas 重算在 T05b 做（G1 之后，由 Claude Code）；本卡只需把新题列进交给 T05b 的清单。

## 交付物

- `questions/new.yaml`、对应的 `refs/`、`scripts/build_refs.py` 覆盖新题。
- 更新后的 `reports/label_distribution.md`。

## 验收

- 每类复杂度来源 ≥ 8 道（含外部基准题）。
- 用户过目全部新题。
